# RPCServer.py 功能分类

## 分类说明

- **一级功能（上层功能）**：高级抽象操作，用户友好的接口，组合操作，业务逻辑相关
- **二级功能（底层功能）**：直接硬件控制，需要了解硬件细节，寄存器级别操作，基础控制

## 使用建议

### 对于普通用户
- **推荐使用一级功能**：更简单、更安全、更直观
- 例如：`SetGripperOpen()` 而不是 `SetPWMServoPulseSingle(1, 2000, 500)`

### 对于高级用户/开发者
- **可以使用二级功能**：更灵活、更精确、更底层
- 例如：需要精确控制时使用 `SetPWMServoPulseSingle()`

### 混合使用
- 一级功能通常内部调用二级功能
- 可以根据需求选择合适的抽象级别

---

## 功能依赖关系

### 一级功能依赖二级功能
- `SetGripperOpen()` → `SetPWMServoPulseSingle()` → `Board.setPWMServoPulse()`
- `SetMecanumVelocity()` → `chassis.set_velocity()` → `SetBrushMotor()`
- `ArmMoveIk()` → `SetBusServoPulse()` + `SetPWMServoPulseSingle()`

### 建议
- 优先使用一级功能，除非有特殊需求
- 二级功能提供更底层的控制能力
- 理解依赖关系有助于调试和优化
